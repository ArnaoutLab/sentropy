# Changelog

Newest first. Version numbers follow the project's release tags.

- **1.7.0** — Batch similarity functions (`@batch_similarity`).
- **1.6.0** — Revamped command-line interface.
- **1.5.0** — Interset ordinariness now deduplicates elements; the Vendi score
  of the overall set is no longer the power mean of the subsets' Vendi scores.
- **1.4.0** — Interset ordinariness; auto-tuned Ray hyperparameters; small
  improvement to the sparse-matrix API.
- **1.3.0** — Faster similarity-sensitive KL divergence.
- **1.2.0** — Vendi score.
- **1.1.0** — Similarity-sensitive cross-entropy.
